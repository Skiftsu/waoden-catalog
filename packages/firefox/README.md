# Mozilla Firefox

**Mozilla Firefox** is a free, open-source web browser developed by Mozilla. It lets you browse websites, search the web, watch videos, download files, and use web applications. Firefox is available for Linux and other major desktop and mobile platforms.

Firefox uses Mozilla's **Gecko** browser engine and emphasizes privacy, security, and user control. It is an alternative to Chromium-based browsers.

## Key Features

- **Privacy protection:** Enhanced Tracking Protection helps block many trackers, while Total Cookie Protection limits cross-site tracking.
- **Private browsing:** Open private windows without saving browsing history or cookies after the session ends.
- **Extensions and themes:** Customize the browser with add-ons, including content blockers, productivity tools, and appearance options.
- **Tabs and bookmarks:** Keep multiple websites open, organize tabs, and save pages for later.
- **Firefox Sync:** Optionally synchronize bookmarks, passwords, browsing history, and open tabs across devices using a Mozilla account.
- **Password management:** Save and manage website logins with the built-in password manager.
- **Developer tools:** Inspect web pages, debug JavaScript, and analyze network activity using integrated tools.
- **Web standards support:** Access modern websites and web applications with support for established web technologies.

## Firefox on Linux

Firefox provides a full-featured desktop browsing experience on Linux. You can use it as your primary browser for everyday tasks, from reading articles and streaming media to online work and web development.
