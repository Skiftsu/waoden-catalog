# PhotoCraft

PhotoCraft is a free, open-source image editor built in Rust. Inspired by Adobe Photoshop, it provides tools for photo editing, digital artwork, and graphic design in a native desktop application that works offline.

## Features

- Layer-based editing with masks, blending modes, and non-destructive adjustments.
- Brushes, selections, filters, text, and vector drawing tools.
- Support for Photoshop PSD and PSB documents, along with common image formats.
- GPU-accelerated rendering and an interface familiar to Photoshop users.

**Development status:** PhotoCraft is in early alpha. Some features are incomplete, and it is not yet intended to replace established tools in professional workflows.
